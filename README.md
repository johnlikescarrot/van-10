## Ghi chú sư phạm

- Ký hiệu: **★** trọng tâm · **◆** mở rộng · **⚠** bẫy · **📌** tự kiểm tra.
- Toàn bộ nội dung viết bằng tiếng Việt, ưu tiên **bảng biểu – sơ đồ – công thức** để dễ nhớ.
